# GitHub Implementations

Minimum required: 5. These are public repositories connected to the research topic.

## 1. AllenAI SciFact
https://github.com/allenai/scifact

Official data and code for scientific claim verification.

## 2. TruthfulQA
https://github.com/sylinrl/TruthfulQA

Benchmark data and evaluation code for TruthfulQA.

## 3. PubMedQA
https://github.com/pubmedqa/pubmedqa

Dataset, preprocessing, evaluation, and human-performance scripts for PubMedQA.

## 4. GPQA
https://github.com/idavidrein/gpqa

Baselines, analysis notebooks, prompts, and evaluation code for GPQA.

## 5. RARR
https://github.com/anthonywchen/RARR

Implementation of retrieval-based attribution and post-hoc revision for unsupported LLM outputs.

## 6. QAFactEval
https://github.com/salesforce/qafacteval

Official implementation of the QAFactEval factual-consistency metric.

## 7. RAGTruth
https://github.com/ParticleMedia/RAGTruth

Dataset and baseline code for hallucination evaluation in retrieval-augmented generation.
