# Tools and Libraries

## 1. Hugging Face Transformers
- **Purpose:** Load, run, fine-tune, and evaluate transformer-based language models.
- **Link:** https://github.com/huggingface/transformers

## 2. Hugging Face Evaluate
- **Purpose:** Reusable evaluation metrics and comparison workflows.
- **Link:** https://github.com/huggingface/evaluate

## 3. Sentence Transformers
- **Purpose:** Produce dense embeddings for semantic similarity and retrieval.
- **Link:** https://github.com/UKPLab/sentence-transformers

## 4. FAISS
- **Purpose:** Efficient similarity search over dense vectors.
- **Link:** https://github.com/facebookresearch/faiss

## 5. Pyserini
- **Purpose:** Information retrieval experiments and reproducible search pipelines.
- **Link:** https://github.com/castorini/pyserini

## 6. Ragas
- **Purpose:** Evaluation of retrieval-augmented generation systems, including faithfulness and retrieval-oriented metrics.
- **Link:** https://github.com/explodinggradients/ragas

## 7. LlamaIndex
- **Purpose:** Build data-connected LLM applications and retrieval pipelines.
- **Link:** https://github.com/run-llama/llama_index
