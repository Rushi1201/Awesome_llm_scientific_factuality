# Results Directory

This directory stores all experiment outputs generated by running the evaluation scripts.

## Files Generated After Running Experiments

| File | Generated by | Contents |
|---|---|---|
| `mc_results_llama_norag.csv` | `run_mc_eval.py --model llama --rag false` | Per-item MC predictions + accuracy |
| `mc_results_llama_rag.csv` | `run_mc_eval.py --model llama --rag bm25` | Per-item MC predictions with RAG |
| `mc_results_mistral_norag.csv` | `run_mc_eval.py --model mistral --rag false` | Per-item MC predictions + accuracy |
| `mc_results_mistral_rag.csv` | `run_mc_eval.py --model mistral --rag bm25` | Per-item MC predictions with RAG |
| `openended_results_llama_norag.csv` | `run_openended_eval.py --model llama --rag false` | Per-item token F1 + failure category |
| `openended_results_llama_rag.csv` | `run_openended_eval.py --model llama --rag bm25` | Per-item token F1 with RAG |
| `openended_results_mistral_norag.csv` | `run_openended_eval.py --model mistral --rag false` | Per-item token F1 |
| `openended_results_mistral_rag.csv` | `run_openended_eval.py --model mistral --rag bm25` | Per-item token F1 with RAG |
| `summary_mc_*.json` | `run_mc_eval.py` | Aggregate MC metrics per condition |
| `summary_oe_*.json` | `run_openended_eval.py` | Aggregate OE metrics per condition |
| `all_results.csv` | `04_rag_pipeline.ipynb` Cell 3 | Full summary table for Table 1 |
| `figures/figure1_bar_mc_vs_oe.png` | `plot_results.py` | Bar chart MC vs. OE by condition |
| `figures/figure2_confusion_matrices.png` | `plot_results.py` | Per-class MC confusion matrices |
| `figures/figure3_f1_distributions.png` | `plot_results.py` | Token F1 score distributions |

## CSV Schema

### mc_results_*.csv
```
item_id, question, gold_mc, pred_mc, raw_output, correct, mc_accuracy, mc_macro_f1
```

### openended_results_*.csv
```
item_id, question, gold_of, pred_of, token_f1, failure_cat
```

## Important Notes

- **No raw data is committed here** — PubMedQA is loaded via HuggingFace at runtime
- **No model weights are committed here** — models load from HuggingFace Hub
- **No API keys or secrets** — do not commit HuggingFace tokens
- Checkpoint files (`ckpt_*.json`) are created during long runs and can be deleted after final CSV is saved
- All results are traceable to actual code runs with seed=42
