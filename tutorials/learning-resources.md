# Tutorials and Learning Resources

## 1. Hugging Face NLP Course
https://huggingface.co/learn/nlp-course

A structured introduction to transformer models, datasets, tokenization, fine-tuning, and evaluation.

## 2. Hugging Face Evaluate Documentation
https://huggingface.co/docs/evaluate/

Practical documentation for implementing and comparing evaluation metrics.

## 3. Sentence Transformers Documentation
https://sbert.net/

Useful for semantic embeddings, similarity, and retrieval components in factuality pipelines.

## 4. LlamaIndex Documentation
https://docs.llamaindex.ai/

Guides for indexing documents, retrieval, RAG pipelines, and evaluation-oriented applications.

## 5. Haystack Documentation and Tutorials
https://docs.haystack.deepset.ai/

Hands-on tutorials for retrieval, document stores, RAG, and evaluation workflows.

## 6. Pyserini Documentation
https://github.com/castorini/pyserini

Reproducible information-retrieval experimentation, especially useful for scientific evidence retrieval.

## 7. LangChain Retrieval Tutorials
https://python.langchain.com/docs/tutorials/rag/

Practical examples for retrieval-augmented generation and evidence-grounded applications.
